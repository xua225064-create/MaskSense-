About Us

MarkSense Multi-Pipeline AI

A multi-agent ceramic mark analysis system that combines OCR, Vision AI, reference matching, database lookup, and web-source verification to produce a clear final report.

Multi
Agent Analysis
600+

Consensus Logic

OCR + Text Reasoning

The system preprocesses the image, crops the mark region, extracts possible Chinese characters, and uses historical mark patterns to reduce common OCR confusion.

Vision AI Reading

Vision AI reads the mark directly from the image as an independent signal, especially useful when OCR is uncertain or seal-script strokes are difficult to segment.

Reference & Web Evidence

Candidate marks are checked against the local reference database and relevant web sources. Source links are shown only when they relate to the analyzed mark.

Consensus

Voting Aggregator

Instead of trusting one result blindly, MarkSense compares OCR, Vision AI, search, and reference-matching outputs before deciding what should appear in the final report.

User Guide

Use MarkSense to upload a ceramic mark image, run silent multi-agent analysis, and review the final recognition report with supporting evidence.

01. Registration & Authentication

Sign in with an account before scanning. Authentication keeps your credit balance, analysis history, and saved reports connected to the right user.

02. Upload & Multi-Agent Analysis

Upload a clear photo of the mark and click "Analyze this image". The system quietly runs OCR, Vision AI, reference matching, database lookup, and web-evidence checks in the background.

03. Voting & Final Report

The aggregator compares all signals and returns one final report. When reliable web sources are available, they appear in Supporting Sources; otherwise the report clearly marks the result as not fully verified.

Frequently Asked Questions

Each analysis uses scan credits from your account. You can continue using the reference library without running a new scan, and you can upgrade when you need more high-speed analyses.

Can the system recognize engraved, faded characters?

+
MarkSense uses both OCR and Vision AI, so it may recover useful signals from faded or seal-script marks. Accuracy still depends heavily on image clarity, lighting, crop quality, and whether the mark exists in reference sources.

How does the analysis history management feature work?

+
When you are signed in, analysis results are saved to your History page so you can revisit previous scans. If you refresh the page, the system reloads saved records from the backend instead of relying only on browser memory.

What is the recognition period limit?
