MarkSense Multi-Pipeline AI

OCR + LLM Verification

The primary pipeline extracts Chinese characters from cropped marks and leverages Large Language Models to contextualize and correct errors based on historical reign titles.

Visual API Recognition

Utilizes advanced multimodal vision models to directly interpret complex, blurred, or calligraphic seals without relying purely on text extraction.

Web Image Search

Automatically reverse-searches the cropped seal images on the web, comparing visual features against auction archives and museum records to find identical artifacts.

Consensus

Voting Aggregator

Instead of relying on a single AI model, MarkSense collects predictions from all pipelines and uses a weighted voting algorithm to reach the final, most reliable conclusion.

User Guide

Start the mark recognition and authentication process with 3 basic steps on the MarkSense Multi-Pipeline AI system.

01. Registration & Authentication

Click "Sign In" in the top right corner. Create a new account or use the one-tap login system (Google) for access. Identification is required to store personal analysis history.

02. Upload & Multi-Agent Analysis

At the main interface, upload a mark image or use drag and drop. Click "Start analysis" to activate the 5 parallel AI pipelines (OCR, Vision, Image Search, ML, etc.) to process the image concurrently.

03. Voting & Final Report

The orchestrator collects results from all pipelines, applies a weighted voting logic, and returns the final verified historical context. All reports are automatically saved in the "History" section.

Commitment

Privacy Policy

The personal data safety of customers and researchers is a top priority at MarkSense AI.

01. Information Collection

We only collect minimal identification data (email) to maintain valid login sessions. Uploaded images are received and processed locally on the server.

02. Data Usage

Images are uploaded directly to serve the analysis algorithm. This data will be hidden fully anonymized if used as part of the training set to improve future OCR accuracy.

03. Protection Mechanism

All data transmission sessions are encrypted with SSL/TLS standards. The user database and image directories have restricted access using multi-layer security architecture.

FAQ

Frequently Asked Questions

Common issues arising during the use of the AI recognition system.

How much does MarkSense AI cost?

+
The system provides database lookup and 5 free initial analysis credits for all accounts. For high-volume storage and recognition needs, users can refer to the premium pricing.

Can the system recognize engraved, faded characters?

+
The system's OCR core can partially restore blurred strokes based on Chinese character context. However, images need to be clear, well-lit, and captured perpendicularly to maximize matching probability.

How does the analysis history management feature work?

+
All recognition tasks are recorded in temporary session memory. We are finalizing the permanent database (along with manual deletion functionality) in the next update.

What is the recognition period limit?

+
The dataset focuses strongly on ceramics from the great Qing, Ming, and Nguyen dynasties. Other periods (Song, Yuan) are being digitized and integrated gradually.
