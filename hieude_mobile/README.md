# HieuDe Mobile

Mobile app built with Expo and React Native.

## Run App

Install dependencies:

```powershell
cd D:\HieuDe_AI\hieude_mobile
npm install
```

Start Expo:

```powershell
npm start
```

Or run directly:

```powershell
npx expo start
```

## Common Commands

Run on Android:

```powershell
npm run android
```

Run on iOS:

```powershell
npm run ios
```

Run on web:

```powershell
npm run web
```

Build iOS preview IPA with EAS:

```powershell
npm run build:ios:preview
```
